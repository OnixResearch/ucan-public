## Runtime and claim boundary

`ucan-core` remains `#![no_std]`; its Cargo manifest has no Aeneas, Charon,
Lean, Nickel, process, filesystem, clock, network, or receipt dependency. Proof
tooling is an explicit checker/CI lane and is not discovered by runtime APIs.
The pre-existing README edit was preserved outside implementation commits.

No Aeneas property proof is claimed. The blocked result does not establish
token validity, clock correctness, parser/codec correctness, cryptographic
correctness, proof-chain soundness, caveat/revocation/replay freshness,
authorization completeness, interoperability, whole-program correctness, or
whole-system security. BLAKE3 binds bytes only and does not establish provider,
translation, model, or verifier soundness.
